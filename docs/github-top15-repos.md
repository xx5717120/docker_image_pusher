## 🌐 public-apis 详细说明

**44 万 Stars |** [public-apis/public-apis](https://github.com/public-apis/public-apis)

### 是什么

一个由社区维护的**免费公开 API 目录**，收集了各个领域的开放 API 接口，做项目、开发原型、学习测试找数据首选。

### 涵盖分类（40+）

| 分类 | 示例 API |
|------|----------|
| 📡 天气 | OpenWeatherMap、彩云天气、wttr.in |
| 🎬 影视 | YouTube、Netflix、Vimeo、IMDb |
| 🎵 音乐 | Spotify、Last.fm、SoundCloud |
| 🐶 动物 | Dog API、Cat API |
| 💰 金融 | 股票数据、汇率、加密货币 |
| 🎮 游戏 | 各种游戏数据接口 |
| ✈️ 交通 | 航班追踪、公交数据 |
| 📖 书籍 | 古登堡计划、Google Books |
| 🧠 AI | 机器学习 API |
| 🇨🇳 国内 | 彩云天气、高德地图、知乎 |

### 使用示例

```bash
# 查上海天气
curl wttr.in/Shanghai

# 随机猫图
curl https://api.thecatapi.com/v1/images/search

# NASA 每日天文图
curl https://api.nasa.gov/planetary/apod?api_key=DEMO_KEY
```
